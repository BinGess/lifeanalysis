# 人生指南 Flutter 客户端 V1

Flutter 3.44.5 / Dart 3.12.2。iOS、Android 共用 `lib/`，中文界面。

## 运行与构建

```bash
flutter pub get
flutter devices
flutter run -d <设备ID>
flutter build apk --release
flutter build appbundle --release
```

iOS 最低支持 15.0，需要 Xcode；真机与发行版本需要配置自己的 Bundle ID、签名团队和证书。Android 需要 Android SDK；正式发行前需配置自己的应用 ID 和发行签名，模板调试签名不用于上架。

默认服务为 `https://vygttv9jhw.coze.site`。切换环境：

```bash
flutter run --dart-define=API_BASE_URL=https://你的服务域名
```

App 直接访问 HTTPS，Android 已声明联网权限。无浏览器 CORS 限制，无需 Python 代理。当前服务无鉴权；客户端没有内置平台密钥。服务未来启用鉴权时需增加用户登录与短期访问令牌，不应把 AI 平台密钥嵌入安装包。

## 页面与交互

底部三个入口：**帮我想想、我的行动、我的**。

输入问题 → 返回完整回答与引用 → 继续追问或手动记一个行动。正文保留服务端结构；长内容通过滚动与引用折叠控制信息密度。目标梳理是可选输入辅助，不是必填问卷。历史和收藏可回看结果；行动支持编辑、完成、暂停、反馈和删除。

追问明确提示将发送相关历史。行动反馈默认仅本机保存，只有用户主动选择重新分析后才提交。清空本机数据不会删除服务端记录。

## 接口

- `GET /health`
- `POST /analyze`
- `POST /analyze/stream`

请求使用 `message` 与可选 `top_k`（1–20，默认不传）。当前线上 SSE 的 data 使用 Python 字面量格式；解析器同时兼容标准 JSON 和受限字面量，不执行代码。只有收到 `done` 且答案非空才标记完成；失败、断流或停止后保留部分结果，不自动重复发起生成。

服务没有结构化澄清问题、行动、会话 ID、恢复任务、取消任务或记录删除接口。客户端不推断这些服务能力。停止接收只关闭本机请求，不保证服务端停止生成；重启后未完成记录可查看、可重试，不能恢复原流。

## 本机存储

使用 SharedPreferences 保存问答、收藏、行动、草稿和设置。无账户同步，也不是加密保险箱。删除问答会保留已单独保存的行动及其问题摘要；清空全部本机数据同时清除行动。

## 结构与验证

- `lib/services/api.dart`：请求、超时、取消与协议检查。
- `lib/services/sse.dart`：SSE 与线上格式兼容。
- `lib/app_state.dart`：问答、上下文、历史与行动状态。
- `lib/ui/screens.dart`：页面与交互。
- `test/`：协议、异常、持久化、上下文及界面测试。

```bash
flutter analyze
flutter test
# 会真实调用线上 AI 服务，仅手动执行：
dart run tool/live_smoke.dart
```

## 系统语音输入（2026-10-05）

首页和结果页追问输入框下提供「语音输入」。点击后请求权限并打开识别预览，点击「说完了」等待最终文字，再点「填入输入框」。新文字追加到原有输入，不自动发起 AI 请求。关闭面板取消本次输入；切到后台停止收音。

通过 [speech_to_text](https://pub.dev/packages/speech_to_text) 接入系统识别：iOS 使用苹果 Speech 框架，已配置麦克风与语音识别用途说明；Android 使用系统识别服务，已声明录音权限与服务查询。不依赖分析服务提供语音接口。Android 当前禁用插件蓝牙扩展，因此不申请蓝牙权限。

默认选择系统支持的中文，单次最多约 60 秒，停顿后系统可能提前结束，支持再次录入。识别过程可能由系统通过网络处理，不承诺完全离线；客户端不保存音频、不将音频上传分析 API，确认的文字按原有问答/草稿规则处理。

本次验证：22 项自动化测试通过，包含部分结果替换、原文保留、确认填入、权限拒绝、关闭时权限仍未返回、停止超时与重试、后台取消、无结果和长度限制；iOS 模拟器构建及苹果原生授权弹窗验证通过。尚未验证真机实际收音、识别准确率及安卓设备运行。
